# Задачник

**Ученици помагат на ученици.** Задачник е уеб приложение, в което ученик снима условието на задача, с която е заседнал, качва го и получава решения с обяснения от съученици. Всеки може да решава чужди задачи, да гласува за най-полезните решения и да събира точки и значки.

> Статус: фронтенд прототип. Данните засега са примерни и са в кода. Предстоят React Router и бекенд.

## Функционалности

- **Задачи:** списък с филтри по предмет и клас, карти със статус („Без решение“, „1 решение“, „Решена“), брой коментари и време.
- **Страница на задача:** снимка на условието с преглед на цял екран и мащабиране, решения с гласуване, подсказка и пълно решение като спойлер, „Най-добро решение“, форма за ново решение.
- **Качване на задача:** снимка, заглавие, предмет, клас, описание и етикети.
- **Класация и профил:** седмична класация по точки, профил със значки и статистика.
- **Блог:** избрана статия, категории, статии с обложки, страница на статия със съдържание и абониране за бюлетин.
- **Вход и регистрация:** избор Ученик/Учител, клас или предмет, училище, показване на паролата и индикатор за силата ѝ.
- **Известия:** камбанка с брой непрочетени и панел с известия.
- **„Как работи“:** стъпки, точкова система, значки, правила и често задавани въпроси.
- **Състояния на интерфейса:** skeleton карти при зареждане, празни резултати и грешка.
- **404 страница** за непознати адреси.
- **Тъмна тема** с геометричен фон, адаптивен дизайн за телефон, таблет и компютър.

## Технологии

- [React 19](https://react.dev)
- [Vite](https://vite.dev)
- CSS (без библиотеки), шрифтове Inter и Caveat от Google Fonts
- ESLint

## Стартиране

Нужен е [Node.js](https://nodejs.org) 20.19 или по-нов.

```bash
git clone https://github.com/SimonaShalevaa/zadachnik.git
cd zadachnik
npm install
npm run dev
```

Сайтът се отваря на `http://localhost:5173`.

### Команди

| Команда           | Какво прави                               |
| ----------------- | ----------------------------------------- |
| `npm run dev`     | стартира сървър за разработка             |
| `npm run build`   | създава готова за публикуване версия в `dist/` |
| `npm run preview` | показва билднатата версия локално         |
| `npm run lint`    | проверява кода с ESLint                   |
