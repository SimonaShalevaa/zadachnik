# Задачник

Задачник е сайт, в който ученици си помагат с домашните. Ако си заседнал на някоя задача, я снимаш и я качваш, а другите ученици могат да напишат решение.

Проектът е за изпита по ReactJS в SoftUni (септември 2026).

## Какво може да прави потребителят

**Без регистрация:**
- да разглежда всички задачи и да ги филтрира по предмет и клас
- да отвори задача и да види снимката в голям размер
- да разглежда профилите на другите и класацията
- да чете блога и страницата „Как работи“

**След вход:**
- да качи нова задача (снимка, заглавие, предмет, клас, описание и етикети)
- да редактира и изтрива **само своите** задачи
- да пише решения (в процес на разработка)

## Технологии

- React 19 + Vite
- React Router 7
- Supabase (база данни, вход/регистрация и съхранение на снимките)
- обикновен CSS

## Как да стартирам проекта

Трябва да имаш инсталиран [Node.js](https://nodejs.org) (версия 20.19 или по-нова).

1. Клонирай проекта и инсталирай пакетите:

```bash
git clone https://github.com/SimonaShalevaa/zadachnik.git
cd zadachnik
npm install
```

2. Направи файл `.env.local` в главната папка. Можеш да копираш `.env.example` и да попълниш стойностите от Supabase (Project Settings → API):

```
VITE_SUPABASE_URL=адресът на проекта
VITE_SUPABASE_KEY=publishable (anon) ключът
```

3. Стартирай:

```bash
npm run dev
```

Сайтът се отваря на `http://localhost:5173`.

Други команди:
- `npm run build` – прави версия за публикуване в папка `dist`
- `npm run preview` – пуска билднатата версия
- `npm run lint` – проверка с ESLint

## Страници

| Адрес | Страница | Достъп |
| --- | --- | --- |
| `/` | Начало | всички |
| `/tasks` | Всички задачи (каталог) | всички |
| `/tasks/:taskId` | Детайли за задача | всички |
| `/tasks/:taskId/edit` | Редакция на задача | само автора |
| `/upload` | Качване на задача | влезли потребители |
| `/users/:userId` | Профил | всички |
| `/leaderboard` | Класация | всички |
| `/blog` | Блог | всички |
| `/blog/:postId` | Статия | всички |
| `/how-it-works` | Как работи | всички |
| `/login` | Вход | само невлезли |
| `/register` | Регистрация | само невлезли |
| `*` | 404 | всички |

Страниците за влезли потребители са защитени с `PrivateRoute`, а вход и регистрация – с `GuestRoute`.

## База данни (Supabase)

- `profiles` – данните на потребителите (име, роля, клас, училище, точки). Профилът се създава автоматично при регистрация.
- `tasks` – задачите. Всеки може да ги чете, но само авторът може да ги променя и трие.
- `task-images` – папка (bucket) в Storage за снимките на задачите.

## Структура на папките

```

├── utils/        помощни функции
├── App.jsx       маршрутите
├── main.jsx
└── supabase.js   връзката със Supabase
public/
└── assets/
    └── styles.css
```
